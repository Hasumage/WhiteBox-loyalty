# Nearloy Hunt: Рекламная сеть Яндекса

## Что подключено

Для Hunt добавлен клиентский компонент РСЯ `YandexRtbAd`. Он загружает официальный скрипт РСЯ:

```text
https://yandex.ru/ads/system/context.js
```

и рендерит RTB-блок через `Ya.Context.AdvManager.render`.

## Переменные окружения

```env
NEXT_PUBLIC_YANDEX_RSYA_ENABLED=true
NEXT_PUBLIC_YANDEX_RSYA_HUNT_FEED_BLOCK_ID=R-A-XXXXXXX-Y
```

Если `NEXT_PUBLIC_YANDEX_RSYA_HUNT_FEED_BLOCK_ID` не задан, рекламный слот не рендерится вообще. Это нужно, чтобы локальная разработка и тестовые окружения не показывали пустые блоки.

Чтобы временно отключить РСЯ без удаления `blockId`:

```env
NEXT_PUBLIC_YANDEX_RSYA_ENABLED=false
```

## Текущее размещение

Первый безболезненный слот добавлен в ленту Hunt:

- после третьего поста;
- затем после каждого шестого следующего поста.

Так реклама не ломает первый экран, не мешает действиям с постом и появляется вместе с динамической догрузкой ленты.

## Где можно добавлять дальше

Подходящие места:

- между постами в общей ленте Hunt;
- после блока готовых коробок в магазине;
- в каталоге персонажей после нескольких рядов карточек;
- в публичных share-страницах постов/карточек, если трафик будет приходить извне.

Пока намеренно не добавлены:

- экран создания поста;
- попап открытия сундука;
- попап улучшения карточки;
- бой.

В этих местах реклама будет мешать основному действию и ухудшит конверсию.

## Важные правила

- Реальный `blockId` нужно взять в кабинете РСЯ после добавления площадки и рекламного блока.
- Блок должен быть промаркирован как реклама. В UI уже выводится компактная подпись `Реклама / РСЯ`.
- Для разных мест лучше заводить разные блоки в РСЯ, чтобы отдельно смотреть доходность и поведение.
